# DebugAfterDark — 深夜 Debug｜Debug After Dark

把 [imitator](https://imitator.ai-apps.work/) 上的報告改寫成給人聽的 podcast：台灣華語、單人主持、AI 語音合成，
目的是讓還沒讀過報告的人也聽得懂、聽完想去看全文。主持人是 AI 角色 **Ping**。

|---|---|---|
| [EP00](episodes/ep00-intro/) | 嘿，還醒著嗎？（預告集，節目自介） | 定稿 |
