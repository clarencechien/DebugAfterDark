# YouTube 成長策略（活文件）

目標：從 imitator 的 HTML 素材做成影音，最後能日更、全自動上傳。
這份只寫**順序、現況和下一個檢查點**，細節在各自的文件：

- 標題、縮圖、說明欄、開場鉤子：[`hooks.md`](hooks.md)
- 影片版、Shorts、上傳流程：[`video.md`](video.md)
- 每集 podcast 怎麼做（第 0 到 8 步）：[`recipe.md`](recipe.md)

每週一的報表出來後，對照這份更新「現況」和「下一步」。最後更新：2026-11-20。

## 為什麼是這個順序

YouTube 工作室 2026-11-04 到 11-18（全頻道）：

- 曝光 21.7k，93% 來自推薦影片：YouTube 有在推。
- **點閱率 0.71%，是最大的瓶頸。** 照 `hooks.md` 新規則下標的 EP24 之後是 1.71%，舊標題 0.64%，所以包裝有用。
- 觀看有 45% 來自廣告。**所有比較都只看自然流量，排除廣告。**
- 留存：前約 30 秒掉到三成，之後幾乎持平。第二個瓶頸是開頭。

參考 fOx Hsiao（@foxh）的做法：標題要有可搜尋的主題、數字和反差；縮圖用固定模板（白字主題、紅字結論）；畫面上放出處；說明欄透明列來源；標示 AI 生成。

## 四條線

四條線可以並行，不用等前一條的結果。Shorts 測鉤子和觸及，長片影片版測留存；Shorts 學到的鉤子寫法再套回長片開頭。
