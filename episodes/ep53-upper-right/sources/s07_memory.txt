報告 QA：「auto memory 開著，它越用越懂我，很好啊？」體感：跨 session 記得我的專案，這是純粹的加分。實情：方便是真的，但有三個代價要知道。第一，它是在位者優勢製造機：你用最久的工具知道得最多，表現最好，跟模型品質無關。你在比的是「共事三個月的同事」和「第一天上班的人」，而且偏誤會複利（越好用就越常用，越常用記得越多）。第二，它會把一次性的抱怨變成永久政策，而且是靜默的。定期跑 /memory 稽核它記了什麼。第三，它是廠商格式，搬不走。你寫下來的 CLAUDE.md、skills 和 hook 是純文字，可以整包搬去任何一家。累積可搬的資產，稽核搬不走的方便。
