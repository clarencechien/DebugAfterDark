每次成功的成本，三個中國模型是 52 到 143 美元，美國組合是 185 到 411 美元。但完成率低，成功一次要走 3,900 到 7,100 步，美國組合是 500 到 3,050 步。加上人工兜底之後，只比 single 模式，三個中國模型的總成本最低（231 到 237 美元，美國 242 到 272 美元）。美國模型開了批次工具呼叫，Opus 4.7 以 230 美元反超。算交叉點：人工重做一題的成本只要超過約 190 到 230 美元，完成率較高的 Opus 4.7（batched）就比三個中國模型便宜。本篇假設的 240 美元，已經在線的另一側。
HAL 的結果方向一致：九個模型裡，DeepSeek R1 是唯一在九個 benchmark 上從未落在成本與準確率 Pareto 前緣的模型。HAL 也記下一件和分母有關的小事：「Together AI changed their DeepSeek R1 endpoint to serve DeepSeek R1 0528 on release day, keeping the same API endpoint name.」[49]。同一個名字底下，模型換了。
使用面上，中國開放模型在 OpenRouter 上一年平均約佔 13% 的 token 用量，某些週接近三成。同一份研究發現需求對價格不敏感：「a 10% decrease in price corresponds to only about a 0.5–0.7% increase in usage」。[93]
「追上多少」要先問用哪一把尺。能力落後五到八個月。單價便宜三到十幾倍。按指數每一分算，只比 GPT-6 Astra 便宜 1.2 到 3.2 倍。放進長時程的 agent 任務、加上人工兜底，差距幾乎歸零，交叉點就落在人工一題兩百美元上下。價差先被 token 用量吃掉一大半，剩下的再被兜底人工吃掉，最後決定帳單的是完成率。這裡沒有替哪一邊說話，只是同一件事又換了一次分母。
