7 月，寫《Clean Code》的 Uncle Bob 說他不讀 agent 寫的程式碼，工程師吵了一整個夏天。這篇把他從去年 12 月到今年 9 月的做法排成一條線。他讀的東西沒有變少，是換了一批，而且換了不只一次。下篇看 Lauren Tan，她往同一個方向走，看的東西不一樣。

品名no-look coding · Robert C. Martin（Uncle Bob）

7 月 23 日，有人在 X 上質疑不審 AI 產出的做法，他回了一則。他說自己從 1960 年代末開始寫程式，現在的策略是「not read any of the code written by my agents」，因為這是用得上 agent 產能的唯一辦法。替代做法是用很嚴的限制把 agent 圍起來。

這句話後來被轉成「Clean Code 的作者不讀 code 了」。照這張表，比較準的說法是：他不讀實作和單元測試，改讀規格。

（注意：英文詞用台灣工程師的念法帶過：Uncle Bob、Clean Code、agent、prompt、context、Gherkin、CRAP、mutation testing、TDD、QA、story 保留英文；技術名詞第一次出現時配一句中文解釋，之後擇一。人名只留 Uncle Bob、Robert Martin、Greg Wilson，其他人名不要加進來。說「這份報告說」，不要只說「報告」。誰說的要照素材：分工、做法、說法是 Uncle Bob 的；比喻和判讀是這份報告作者的。Ping 沒有個人經歷，不加個人反應。草稿段尾的小問題或轉折要保留。不要用「你猜怎麼著」。不要預告下一集，也不要提其他人的做法。）
