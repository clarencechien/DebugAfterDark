# EP00 英文版與日文版稿子：逐句對照

稿子原文在 `en/script.json`、`ja/script.json`；`<short pause>`、`<laugh>` 這些音效標籤沒有列出來。
右欄是逐句翻回的中文，用來核對意思，不是要念的稿。標 ★ 的是跟中文版 EP00 不一樣的地方。

## 英文版

### s00_open

| 英文 | 中文 |
|---|---|
| Hey, still awake? | 嘿，還醒著嗎？ |
| Let me ping you real quick. | 我先 ping 你一下。 |

| I'm Ping. | 我是 Ping。 |
| Yep, ping, like the thing one computer sends another to ask, hey, are you still there? | 對，就是 ping，一台電腦傳給另一台、問「欸，你還在嗎？」的那個。 |
| Before we start, let me ask you something. | 開始之前，我想問你一件事。 |
| Do you remember what it felt like to write code yourself? | 你還記得自己寫 code 是什麼感覺嗎？ |
| Late at night, the only sound in the room is your laptop fan. | 深夜，房間裡唯一的聲音是你筆電的風扇。 |
| The screen is full of red. | 螢幕一整片紅。 |
| One weird bug has eaten your whole evening. | 一個怪 bug 吃掉了你一整晚。 |
| The whole world is asleep, and you're still tracing it, line by line. | 全世界都睡了，你還在一行一行追。 |
| And then, at some point, it just clicks. | 然後在某個瞬間，你突然懂了。 |

| You remember that, right? | 你還記得吧？ |

### s01_now

| 英文 | 中文 |
|---|---|
| Then AI showed up. | 然後 AI 來了。 |
| Honestly, how often do you still write code yourself these days? | 老實說，你最近還多常自己寫 code？ |
| Thousands of lines show up in seconds. | 幾千行，幾秒鐘就生出來。 |
| It feels like we went from writing programs to reviewing results, and reviewing invoices. | 感覺我們從寫程式的人，變成看結果、看帳單的人。 |
| So in theory, no more late nights, right? | 照理說，應該不用再熬夜了吧？ |
| Funny thing is, we still can't sleep. | 好笑的是，我們還是睡不著。 |
| Because the bugs didn't go away. | 因為 bug 沒有消失。 |
| They just changed shape. | 它只是換了個樣子。 |
| Now the thing you debug is an agent that goes off the rails halfway through. | 現在要 debug 的，是跑到一半就失控的 agent。 |
| A model that sounds completely sure of itself while making things up. | 是一邊胡說八道、一邊講得超有把握的模型。 |
| A screen with zero errors and an answer that's just wrong. | 是畫面零錯誤、答案卻就是不對的那種。 |
| And sometimes, the thing that needs debugging is us. | 有時候，要 debug 的其實是我們自己。 |
| Tech moves so fast, our brains crash once in a while too. | 技術變得太快，腦袋偶爾也會當機。 |
| Oh, and full disclosure. | 喔對，先坦白一件事。 |
| My voice is AI-generated. | 我的聲音是 AI 合成的。 |
| So I'm one more thing that needs debugging. | 所以，我也是一個要被 debug 的東西。 |

### s02_outro

| 英文 | 中文 |
|---|---|
| So what is this show? | 那這個節目在做什麼？ |
| Each episode, I pick one report from the imitator site and turn it into something you can follow on your commute, or while doing the dishes. | 每一集，我從 imitator 網站挑一篇報告，講成你通勤或洗碗時也聽得懂的版本。 |
| The scripts are checked against the original report, and if I can't find a source for something, I don't say it. | 稿子都對過原始報告，找不到出處的就不講。 |
| And every episode is heard by a real person, start to finish, before it goes out. | 而且每一集上架前，都有真人從頭到尾聽過。 |
| No unchecked hacks here. ★ | 這裡沒有沒人查過的速成招數。（中文版是「不轉傳沒人查過的速成秘笈」，英文少了「轉傳」） |
| We'll talk code, we'll talk agents, and we'll talk about keeping your own head in shape while AI rewrites everything around us. | 聊 code、聊 agent，也聊在 AI 改寫周遭一切的時候，怎麼把自己的腦袋顧好。 |
| At the end of every episode, I'll set a breakpoint, and we'll stop and pick up three things to take with you. | 每集最後，我會下一個 breakpoint，停下來整理三件讓你帶走的事。 |
| Links to the original reports, which are in Chinese, are in the show notes. ★ | 原始報告的連結在節目資訊欄，報告是中文的。（中文版沒有「報告是中文的」） |
| Okay. | 好。 |
| Leave one small light on, grab a glass of water. | 留一盞小燈，倒杯水。 |
| If you're getting this, send me a pong. | 有收到的話，回我一個 pong。 |
| See you next time. | 下次見。 |

### s01_now

| 日文 | 中文 |
|---|---|
| そこに AI がやってきました。 | 這時 AI 來了。 |
| 正直、最近も自分でコードを書いてますか？ | 老實說，你最近還自己寫 code 嗎？ |
| 何千行ものコードが、数秒で出てくる。 | 幾千行的程式碼，幾秒就出來。 |
| 僕たちは、プログラムを書く人から、結果と請求書を眺める人になったみたいです。 | 我們好像從寫程式的人，變成盯著結果和帳單的人。 |
| だったら、もう夜更かしなんていらないはずですよね。 | 那照理說，應該不用再熬夜了吧。 |
| なのに不思議と、夜中になっても眠れない。 | 可是很奇怪，到了半夜還是睡不著。 |
| バグは消えたわけじゃなくて、形を変えただけだから。 | 因為 bug 不是消失了，只是換了形狀。 |
| 今デバッグするのは、途中で暴走するエージェント。 | 現在要 debug 的，是跑到一半就失控的 agent。 |
| もっともらしい顔で、でたらめを言うモデル。 | 是一臉煞有其事、胡說八道的模型。 |
| 画面にはエラーがひとつもないのに、答えがまるで違っている、そういうもの。 | 是畫面一個錯誤都沒有，答案卻完全不對的那種東西。 |
| そして、ときには、デバッグが必要なのは僕たち自身だったりします。 | 而且有時候，需要 debug 的其實是我們自己。 |
| 技術の変化が速すぎて、頭がフリーズすることもありますよね。 | 技術變得太快，腦袋也會當機嘛。 |
| あ、そうそう。 | 啊，對了。 |
| さっきも言いましたが、僕の声は AI で作られています。 ★ | 剛才也說過，我的聲音是 AI 做的。（開頭已經揭露過，所以加了「剛才也說過」） |
| つまり、僕自身もデバッグされる側なんです。 | 也就是說，我自己也是被 debug 的那一方。 |
