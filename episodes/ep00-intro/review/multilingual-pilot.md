# 多語試作：英文版與日文版 EP00（2026-11-04）

目的：看 D1 換語言之後還是不是同一個 Ping、念得清不清楚，決定要不要做英文與日文的獨立節目。
討論與決定的背景見 README 的「收入方式」之後的對話紀錄；架構建議是每種語言一個獨立節目（獨立 feed）。

## 怎麼做的
- 稿子：agent 直接從中文 EP00 改寫（`en/script.json`、`ja/script.json`），每句話都是產線真的有做的事。
  - 英文版照中文版承諾「每集都有真人從頭聽過」，英文由節目擁有者自己審。
  - 日文版在開頭和結尾都口播揭露：台本由 AI 依中文報告寫成、對過原文，**音聲沒有經過日文母語者確認**。
- 語氣：每份稿子用自己語言寫的 `base_style_v5`，`make_podcast.py` 讀 script.json 的 `chars_per_sec`、`mood_joiner`
  （英文 12、日文 7 字／秒），中文稿不受影響。
- 生成：D1、每段 3 次。挑選與檢查：`tools/lang_check.py`（Whisper large-v3-turbo 指定語言盲聽、音高跳動、語速、
  跟中文 Ping 的聲紋相似度），清楚度差 0.02 以內挑最穩的那次。後製：`make_podcast.py master --match-eq`，沒有固定開場。

## 結果

| | 英文 | 日文 | 中文參考 |
|---|---|---|---|
| 長度 | 3:12 | 3:48 | 2:44（EP00） |
| 盲聽錯誤率（選中的） | 0–1.5%（字） | 3.7–10.5%（字元，多半是假名／漢字寫法不同） | EP05 平均 2.8% |
| 整集音高跳動 | 0.179 | 0.200 | EP05 0.234（中文有聲調，數字不能直接比） |
| 跟中文 Ping 的聲紋相似度 | 0.93–0.96 | 0.96–0.98 | 中文各段對平均 0.98–0.99 |

- 聲紋：日文比英文更接近中文 Ping；英文低一點，但仍在 0.93 以上。要不要算「同一個人」以人耳為準。
- 日文盲聽的差異大多是寫法（ひと／一、とき／時、ping／ピング、imitator／イミテーター），可能真的念錯、要請母語者聽的：
  「確かめ合う」「バグひとつ」「出どころ」（被聽成「手どころ」）。
- 檢查紀錄：`en/qa/lang_check.json`、`ja/qa/lang_check.json`。
