Walmart Agent Profiles（2026-10-21）是目前最完整的樣板：agent 在使用者帳號裡有自己的 profile；預設每筆核准，或 50、100、200 美元預授權；agent 拿不到卡號、不能改付款方式、看到的價格和人一樣；退貨流程同樣適用於 agent 的誤操作；違規就封。Amazon 的版本是要求 agent 在 HTTP 請求裡自我識別，不識別就封——Amazon 封的是「不表明身分的 agent」，不是 agent 本身。
Amazon 告 Perplexity：第九巡迴上訴法院 2026-08-04 以 3-0 推翻初步禁制令：「是使用者在存取 Amazon 的電腦」；但同一份判決明言不禁止平台封鎖違反條款的 agent。（原本的理論是 CFAA 電腦詐欺法，若成立任何使用者委託的 agent 都可能被當成駭客。）
